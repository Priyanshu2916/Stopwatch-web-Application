 Stopwatch Web Application

A simple and responsive Stopwatch Web Application developed as part of the SkillCraft Technology Internship Task.

## Features
- Start Stopwatch
- Pause Stopwatch
- Reset Stopwatch
- User-friendly interface
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Objective
This project was created to practice front-end development concepts and build an interactive stopwatch application.
